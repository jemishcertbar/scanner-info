Research Scanner Information

If you found this page from your server logs, this is an independent, small-scale network research project. It is not an attack, and you can opt out at any time.

What is this?

I'm Jemish Certbar, an individual developer building my own network scanner as a learning and research project. It checks which TCP ports are reachable on public IP addresses and identifies the type of service running (for example, a web server or SSH). The scan volume is small and runs at a low, throttled rate.

What the scanner does

  • Opens a normal TCP connection to a limited set of common ports.
  • Reads the service banner, or sends one harmless request (for example, HTTP HEAD / or a TLS handshake).
  • Records whether the port is open, the banner, and basic service/OS hints.
  • Targets are chosen in random order and rate-limited, so any single network sees very little traffic.

What the scanner does NOT do

  • No exploitation or vulnerability attacks.
  • No password guessing or login attempts.
  • No denial-of-service or high-volume traffic.
  • No attempt to access, modify, or download your data.

Data collected and how it's used

  • Stored: IP, port, open/closed status, service banner, timestamp.
  • Used only to test and improve my scanner's accuracy.
  • Stored privately on my own machine. Not sold, published, or shared with third parties.
  • Data for opted-out addresses is deleted on request.
